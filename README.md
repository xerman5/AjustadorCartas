# Maquetador de Cartas · Streamlit

Aplicación de Streamlit para preparar imágenes de cartas por tandas, ajustar el recorte y descargar ZIPs listos para impresión.

## Estructura

```text
streamlit_app.py
requirements.txt
.streamlit/config.toml
uploader_component/__init__.py
uploader_component/index.html
```

## Streamlit Community Cloud

1. Sube todos los archivos del proyecto al repositorio de GitHub.
2. En Streamlit Community Cloud selecciona `streamlit_app.py` como archivo principal.
3. El componente de subida personalizado se carga desde `uploader_component/`.

No requiere Node ni npm.
